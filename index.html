Architecture

ShipForge AI: generate, review, ship

  • Sandbox: no network, memory and CPU limits, 10 s timeout, one folder per run
  • Model fallback: gpt-oss-20b → gpt-oss-120b → qwen3.8-27b → gemini-3.1-flash-lite
  • API: POST /generate, /approve, /reject · GET /status/{run_id}

Design decisions

  • Pushing is never under LLM control. The LLM writes code; the app process does the push, and the GitHub token is never given to the sandbox.
  • The retry limit lives in the graph. An attempts counter with a conditional edge, not a line in the prompt.
  • Human approval is a real pause. interrupt and checkpointing hold the run until you decide; a run can be approved or rejected only once.
  • Untrusted code stays isolated. Docker sandbox plus a secret scan before any push.

JobPilot AI: a tool-routing agent

  • Resume RAG: PDF → chunks → BAAI/bge-small embeddings → Chroma → top passages
  • Model: openai/gpt-oss-20b on Groq, orchestrated with LangGraph
  • Live: deployed on Streamlit Community Cloud

Design decisions

  • The LLM routes, the tools do the work. chat_node decides per query which tool(s) to call and loops until it has enough to answer.
  • Answers are grounded in your resume. RAG over the uploaded PDF, so replies reflect your real skills and experience.
  • Live data instead of model memory. Adzuna for current openings and DuckDuckGo for up-to-date company information.
  • Responses stream. Answers appear token by token in the Streamlit chat.

Architecture

DevForge AI (v1): a self-healing coding agent

  • Four tools: write_code, execute_code, check_result, write_html_code, with conditional routing
  • Limits: 3 retries · recursion limit 15 · 10 s execution timeout
  • FastAPI endpoint with Pydantic validation, separate from the Streamlit UI

Design decisions

  • Self-correcting. After each run the agent captures errors and exit codes and feeds them back to the LLM to fix the code.
  • Python programs and websites. Plain-English requests become working code, or a single-file website with a live preview.
  • Decoupled UI. The agent sits behind a FastAPI endpoint; Streamlit only displays code, output and errors.
  • Superseded by ShipForge AI. The next version adds a Docker sandbox, a graph-enforced retry limit and human approval.
